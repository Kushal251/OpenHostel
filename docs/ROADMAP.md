# Contributor Priority

We classify GitHub issues using the following priority labels.

| Label | Meaning          |
| ----- | ---------------- |
| `P0`  | Critical for MVP |
| `P1`  | High priority    |
| `P2`  | Normal feature   |
| `P3`  | Nice to have     |

---

# Difficulty Labels

| Label              | Estimated Effort |
| ------------------ | ---------------: |
| `good first issue` |        1–2 hours |
| `easy`             |        2–4 hours |
| `medium`           |        5–8 hours |
| `hard`             |         1–3 days |

---

# Milestone Policy

A milestone is considered complete only when:

* All P0 issues are merged
* Documentation is updated
* Tests pass
* CI passes successfully
* Feature is reviewed by maintainers

---

# Vision Beyond Code

OpenHostel is not only a software project—it is an open-source learning ecosystem where students contribute production-ready features, gain real development experience, and collaborate through structured internships and community contributions.
