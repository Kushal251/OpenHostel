# OpenHostel Code of Conduct

## Our Commitment

OpenHostel is an open-source community built by students, for students.

We are committed to providing a welcoming, respectful, and collaborative environment for everyone regardless of experience level, background, identity, or skill set.

Every contributor, maintainer, reviewer, and community member is expected to follow this Code of Conduct.

---

## Our Standards

Examples of behavior that contributes to a positive community include:

* Being respectful in discussions and code reviews
* Giving constructive and actionable feedback
* Helping new contributors learn the project
* Respecting different technical opinions
* Writing clear documentation and maintainable code
* Accepting feedback professionally

---

## Unacceptable Behavior

The following behaviors are not tolerated:

* Harassment or personal attacks
* Discrimination of any kind
* Offensive or abusive language
* Trolling or intentionally disrupting discussions
* Sharing another person's private information without permission
* Plagiarizing code while claiming authorship
* Spam or unrelated promotional content

---

## Code Review Etiquette

When reviewing Pull Requests:

* Critique the code, not the person.
* Explain *why* a change is requested.
* Suggest improvements whenever possible.
* Be patient with first-time contributors.

When receiving reviews:

* Assume good intent.
* Ask questions if feedback is unclear.
* Update your PR respectfully.
* Avoid argumentative discussions.

The goal is to improve the project together.

---

## Communication Guidelines

Use professional and respectful communication in:

* GitHub Issues
* Pull Requests
* Discussions
* Documentation
* Community chats

Disagreements are normal; disrespect is not.

---

## Maintainer Responsibilities

Project maintainers are responsible for:

* Enforcing this Code of Conduct fairly
* Reviewing contributions objectively
* Protecting contributors from harassment
* Keeping discussions focused and constructive
* Making moderation decisions in the best interest of the community

---

## Reporting Issues

If you experience or witness behavior that violates this Code of Conduct, report it privately to the project maintainers.

Include:

* What happened
* Where it happened
* Relevant screenshots or links
* Any additional context

Reports will be handled respectfully and confidentially whenever possible.

---

## Enforcement

Maintainers may take appropriate actions including:

1. Friendly warning
2. Request for behavior correction
3. Temporary restriction from discussions
4. Rejection of contributions
5. Permanent removal from the community in severe cases

Enforcement decisions prioritize the safety and health of the community.

---

## Our Goal

OpenHostel is more than a software repository—it is a collaborative learning environment where students gain real-world engineering experience through open-source development.

Every contributor deserves to learn, contribute, and be treated with respect.
